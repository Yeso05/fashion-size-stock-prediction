# Fashion – Which Sizes Should We Stock?

## Project Overview

This project analyzes fashion retail sales and return data to determine
the ideal size mix for inventory stocking.

The project uses Exploratory Data Analysis and Random Forest Regression
to understand size-wise demand across stores, regions, and seasons.

## Objectives

- Analyze demand across different clothing sizes
- Compare size demand across regions
- Identify seasonal demand patterns
- Analyze unusual product-size return patterns
- Calculate the ideal size mix for stores
- Predict units sold using Random Forest Regression
- Provide practical inventory stocking recommendations

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- GitHub

## Machine Learning

Algorithm:

Random Forest Regression

### Features

- Product ID
- Size
- Store ID
- Region
- Season
- Customer Demographics
- Month

### Target

Units Sold

### Evaluation Metrics

- MAE
- RMSE
- R² Score

## Key Outcome

The project generates store-specific size mix recommendations to help
fashion retailers allocate inventory based on historical demand.

## Dataset

The dataset used in this academic project is synthetically generated
for analysis and machine learning purposes.
